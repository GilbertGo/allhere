0. 시험판에 대해

시험판은 실제 앱 코드를 그대로 웹으로 내보낸 것입니다. 그래서 화면, 화면 이동, 버튼, 문구가 안드로이드 앱과 같습니다.

  • 아래 화면별 바로 가기 링크로 원하는 화면을 바로 열 수 있습니다.
  • 휴대폰 크기 창(폭 360~420px)으로 보면 실제와 가장 비슷합니다.
  • 처음 열면 예시 기록이 들어 있습니다(공사 보수, 소방 점검, 시설 점검, 일상 앨범 등).
  • 시험판에서 만든 기록은 그 브라우저 안에만 저장됩니다. 서버로는 아무것도 보내지 않습니다.
  • 처음 상태로 돌리려면 사이트 데이터를 지우세요(localStorage).

1. 앱 개요

사진통은 현장 사진을 찍어서 바로 **보고서(사진대지)**로 만드는 앱입니다.

  • 주 사용자: 아파트·건물 관리사무소 시설 담당, 소규모 보수·설비 업체 작업자. 혼자 찍고 정리하는 사람.
  • 최종 결과물: A4 사진대지 PDF. 관리사무소 월간 업무 보고, 소방 지적사항 조치 보고(조치 전·후), 시설 정기 점검 사진첩 등.
  • 핵심 차별점:
    • 찍을 때 사진 위에 보드판(공사명·일자·위치·공종·업체 표)이 들어갑니다.
    • 작업 종류에 맞는 사진대지 형식이 바로 나옵니다.
  • 로그인 없이 쓸 수 있습니다. 로그인은 팀 기록(현장 공유)에서만 필요합니다.
  • 같은 코드에서 '작업통'(팀용, 로그인 중심)도 나옵니다. 이 시험판은 사진통입니다.

3. 화면별 설명

3-1. 홈

  • 맨 위: 배경 그림, 앱 이름, "찍은 사진을 바로 정리하고, 보고서까지", ☰ 메뉴(내 정보·친구 초대·설정·소통실).
  • 간편 모드: [찍기 / 불러오기]와 [사진대지 / 앨범] 두 카드. 설정 없이 바로 시작합니다.
  • 용도별 전문 기록 모드: 공사·작업, 시설·점검, 일상·생활 세 칸.
  • QR 코드: 판독, 만들기.

3-2. 찍기 화면(사진 글상자)

  • 카메라 화면 위에 보드판이 흐릿하게 보이고, 찍으면 보드판이 사진에 들어갑니다.
  • [보드판 수정]:
    • 모양(보드판 없음·카드·가로 띠·세로 기둥·글씨만·표·표+제목띠·표 두 칸)
    • 크기(아주 작게~크게)
    • [처음 자리로]
    • 보드판은 끌어서 옮길 수 있습니다.
  • [글 수정]: 제목·일자·위치·내용·담당. 일자와 위치는 저절로 채워집니다.
  • 음성 입력: 말로 칸을 채우고 "찍어"라고 하면 찍힙니다. 장갑 모드 = 휴대폰을 똑똑똑 두드려 켜기.
  • 간편 모드에서 찍은 뒤의 편집 화면:
    • [글 수정], [보드판 수정], [보내기]
    • 저장 버튼 이름이 상태에 따라 바뀝니다: [사진첩에 저장] / [저장됨 ✓] / [고친 사진 저장]

3-3. 사진대지 형식 3가지

  1. 칸별 사진대지: A4 한 장에 2·4·6·9·12·16칸.
    • 사진은 자르지 않고 칸에 맞춥니다.
    • 칸 이름표는 눌러서 고칩니다.
    • 사진을 꾹 누른 뒤 다른 칸을 누르면 자리가 바뀝니다.
    • 위쪽에 [저장]과 ⋯가 있습니다. ⋯ 안: 인쇄, 새 사진대지, 앨범에서 한꺼번에 넣기, 사용설명서 등.
  2. 조치 전·후(소방·보수·수리·하자이면 기본으로 골라짐):
    • 표지: 네모 제목, 내용 요약, 년월, 현장 표. 눌러서 고칩니다.
    • 항목마다 [조치 전 | 조치 후] 사진 두 장과 설명.
    • '조치 후 남음' 표시, [조치 후 n건 찍기].
    • 사진 칸을 누르면: 설명 고치기, 앨범 사진으로 바꾸기, 이 사진 빼기, 또는 빈 칸이면 카메라로 찍기/앨범에서 넣기.
    • PDF: 표지 + 한 쪽에 3건.
  3. 점검 사진첩(시설·점검 모드):
    • 결과 요약(항목·양호·불량·조치 완료·미점검).
    • 2열 칸: 사진, 항목, 결과, 내용.
    • 결과를 누르면 양호 → 불량 → 조치 완료 순으로 바뀝니다.
    • 불량 칸은 [조치 전·후로] 만들 수 있습니다.
    • PDF: 표지 + 요약 표 + 한 쪽 6칸.

세 형식 공통 버튼(아래쪽):

  • [사진대지 작성 완료]:
    • 누르면 [완료](작업함으로 나가기) 또는 [완료하고 보내기]를 고릅니다.
    • 완료하면 작업함에 '작성 완료' 표시가 붙습니다.
    • 다시 누르면 작성 중으로 되돌릴 수 있습니다.
  • [PDF 보내기]: [PDF만] 또는 [PDF + 사진 n장](원본 사진도 함께 보냄).
  • [사진으로 보내기]: 사진대지 전체를 긴 사진 한 장으로 보냅니다.
  • 고친 내용은 저절로 저장됩니다.

3-4. 작업함

  • 내 작업 목록. 작업별·날짜별·공종별·장소별로 볼 수 있습니다.
  • 표시 배지: 진행 중, 작성 완료, 예시.
  • 누르면 그 사진대지가 열립니다.
  • 위쪽은 '최근 사진'(휴대폰 사진 권한이 있을 때).

3-5. 일상·생활 → 앨범

  • 일상·앨범 만들기 화면:
    • [작성하던 앨범 불러오기]
    • ① 무슨 앨범(여행·음식/맛집·가족/모임·반려동물·기념일·취미·기타)
    • ② 제목, 함께한 사람(선택)
    • 지난 앨범
    • 아래에 [앨범에서 불러오기] · [찍기]
  • 사진 고르기(그날 찍은 사진 제안 포함) → 틀 고르기(여행 이야기·폴라로이드·모자이크) → 앨범.
  • 앨범은 표지와 쪽을 옆으로 넘겨 봅니다.
  • 제목·글은 눌러서 고치고, 사진은 빼거나 바꿀 수 있습니다. 전체 공유는 긴 한 장으로 보냅니다.

3-6. 내 정보

  • 로그인 상태, 친구 초대, 설정, 소통실, 앱 정보.
  • [예시 기록 보이기] 스위치.

4. 직접 해 볼 만한 흐름(시나리오)

  1. 보수 작업 조치 전·후
    • 홈 → 공사·작업 → ① 보수·수리 → ② 공사명 → ③ 조치 전·후 → [카메라 열기]
    • '보수 전' 찍기 → 저장 → [보수 후]로 바꿔 찍기 → 저장 → [다 찍음]
    • 사진대지 → 설명 고치기 → [사진대지 작성 완료]
  2. 찍다가 멈추고 이어 하기
    • 찍는 중에 ← → [잠시 멈춤]
    • 공사·작업 화면 맨 위 '진행 중' → [이어서 찍기]
  3. 지난 사진대지 다시 열기
    • 공사·작업 화면 [작성하던 사진대지 불러오기] → [보기] / [이어서] / [새로]
  4. 시설 점검
    • 홈 → 시설·점검 → ① 승강기 등 → ③ 점검 사진첩 → [카메라 열기]
    • 찍고 결과(양호·불량) 고르기 → 점검 사진첩
    • 불량 → [조치 전·후로]
  5. 빠른 사진대지
    • 홈 → [사진대지 / 앨범] → 칸에 사진 넣기 → [저장] → ⋯ [새 사진대지 만들기]
  6. 일상 앨범
    • 홈 → 일상·생활 → ① 여행 → ② 제목 → [앨범에서 불러오기] → 틀 → 앨범 → 제목 고치기

5. 지금까지 정한 원칙(검토할 때 참고)

  • 현장 작업자는 장갑을 끼고 바쁩니다. 그래서 누르는 횟수를 줄이고, 버튼은 크게, 글은 쉬운 말(존댓말 '~해요')로 씁니다.
  • 기존 기능은 지우지 않고 ⋯ 안으로 옮겨서 정리합니다.
  • 저장은 저절로 되게 하고, 사용자가 확인할 수 있는 버튼([저장], [작성 완료])도 따로 둡니다.
  • 형식은 실제 업체·관공서 양식을 따랐습니다(소방 이행완료 보고서의 건별 전·후 사진, 업체 사진대지, Excel 조치 사진첩).
