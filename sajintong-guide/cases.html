①

현장 사진 한 장씩 빨리

간편 모드 · 손이 바쁠 때 · 예) 계단 청소 확인

이렇게
  1. 앱을 열면 카메라가 바로 떠요.
  2. 대고 1초 가만히 있으면 자동으로 찍혀요. 말로 찍어, 가운데 셔터도 돼요.
  3. "찍었습니다" 뒤에 제목을 말해요. 지난 제목 그대로면 그대로. 지금 듣는 칸은 노랗게 깜빡여요.
  4. 이어서 세부내용을 말하고, 확인 창에서 그대로(저장) 또는 수정. 일자 · 위치 · 담당은 자동이에요.
  5. 저장한 사진이 크게 떠요 → 찍어(다음 사진) 또는 보내기(카톡).
잘 쓰는 법 다음 사진까지 시간이 있으면 위 오른쪽 ⏸ 잠시 멈춤. 다 찍으면 왼쪽 아래 찍은 사진 · N장 → ⚡ 사진대지 자동 작성.
②

보수 공사 전 · 중 · 후

사진대지바로 제출
이렇게
  1. 메인 → 공사·작업 → 종류 보수 · 수리 → 세부 작업명 '지하주차장 누수 보수'.
  2. 카메라 열기 → 위 칸 줄에서 수리 전을 고르고 찍어요.
  3. 앱을 닫아도 돼요. 다음 날 다시 공사·작업에 들어가면 맨 위 '찍는 중' 카드 → 이어서 찍기 → 수리 중, 그다음 수리 후.
  4. 다 찍으면 왼쪽 아래 다 찍음 · 사진대지 → 전 · 중 · 후가 칸에 들어간 사진대지 → 보내기(PDF).
잘 쓰는 법 지적사항 여러 건을 고치는 일이면 형식을 조치 전 · 후로 고르세요. 건마다 전 · 후 사진이 짝지어져요.
③

월간 소방 점검

맞춤 모드 · 시설·점검 · 예) 101동 1층 → 5층

이렇게
  1. 메인 → 시설·점검 → 사진보드 → 소방 → 어떻게 돌아요 공간 순 → 시작 위치 101동 · 1층 → 찍기 시작.
  2. 아래 장비 ▾에서 고르고 찍어요. 양호면 그냥 두고, 문제면 불량을 누르고 한마디.
  3. 층을 다 찍으면 다음 공간 ▶. 빠뜨린 장비가 있으면 앱이 먼저 알려 줘요.
  4. 마치기 → 사진 보내기 또는 사진대지로 묶기.
잘 쓰는 법 다음 달엔 시설·점검 맨 위 지난번처럼 101동 한 번이면 같은 설정으로 바로 시작해요. 자세한 것은 시설·점검 설명서.
④

찍어 둔 사진 → 사진대지

어디서든 · 사진만 찍어 두고 정리는 나중에

이렇게
  1. 메인 사진대지 생성 → 사진대지 자동. 오늘 찍은 사진보드가 바로 정리돼요.
  2. 다른 날 사진이면 다른 날 사진보드로 자동 작성 → 사진을 누르거나 날짜 옆 이날 모두 → N장 → 사진대지 N개 만들기.
그러면 보드판 글대로 시설명 · 날짜별로 나뉘고, 층 → 내용 순서로 놓이고, 칸 이름도 '2층 감지기'처럼 저절로 들어가요. 직접 넣고 싶으면 사진대지 수동.

공통으로 알아 두면 좋은 것

  • 사진은 갤러리의 '사진통' 폴더에 저장돼요(점검은 점검마다 폴더).
  • 음성 안내가 안 들리면 옵션 안내 › 🔊 음성 안내 시험으로 확인하세요.
  • 보드판은 손가락으로 끌어 옮길 수 있어요.
